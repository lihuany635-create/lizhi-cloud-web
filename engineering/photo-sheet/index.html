施工照片填表

批次碼—
1

從資料夾選照片

電腦版 Chrome／Edge 可以連結整個資料夾，下次開網頁按「重新連接」即可。手機會改成一般選照片。

2

檢查表

照片已依設定統一尺寸並照拍攝時間排序。說明可以手打，也可以讓 ChatGPT 回填。

3

給 ChatGPT 看照片、回填說明

產生編號拼圖（每張最多 12 格），連同提示詞丟給 ChatGPT。它讀完小白板後透過 MCP 回填，或把它的回覆貼到下面。



    
    
    


    

      MCP 即時回填（Supabase） 未連線
      

        
        
      

      

      
ChatGPT 的 MCP 工具 fill_cells 寫入下面這張表，網頁會即時把文字填進對應編號。

      create table public.photo_fills (
  batch text not null,
  cell int not null,
  text text not null,
  updated_at timestamptz default now(),
  primary key (batch, cell)
);
alter table public.photo_fills enable row level security;
create policy "read fills" on public.photo_fills
  for select to anon, authenticated using (true);
alter publication supabase_realtime add table public.photo_fills;
