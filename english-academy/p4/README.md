# P4｜AI 適性教學、學習計畫與技能追蹤 — 隔離開發候選

> **尚未部署。** 所有輸出均以匿名合成學習資料產生；不會讀取正式 Supabase、ChatGPT 對話、Google 登入或私人錯誤紀錄。本候選不是實際 LLM 教學服務，也不是正式 CEFR 評估。

## 核心模組
- `adaptive-planner.mjs`：六項技能的弱項證據、FSRS 到期卡與每日目標時間結合，推薦複習、課程或輕量對話；不因久未練習扣分，不從沒有證據的能力推論弱點。
- `curriculum.mjs`：A0–C2 參考階段的生活、聽說讀寫與技術表達課程；每項技能獨立保存階段，具多日練習及雙測驗的人為進階審核門檻；不自動升級或認證 CEFR。
- `learning-report.mjs`：僅使用已保存、附識別碼的練習和真實學習時數編製每週報告。客觀題與主觀自評分開，缺資料為 null，無未學習日扣分。
- `error-drills.mjs`：根據有來源編號的錯誤類別推薦模板題；不反映原始私人句子，也不自行把模板當作已完成練習。
- `validateTeacherProposal`：給將來的 LLM 教學建議設證據白名單與權限限制，拒絕捏造 CEFR 或不經本人同意更改正式單字、學習紀錄。
- `preview/`：手機優先的展示頁，含今日學習、課程地圖、週報、錯題補強。**只操作本頁匿名資料，重新載入後重置。**

## 在本機檢視候選
取得此非 main 分支後，於倉庫根目錄執行：
```bash
python -m http.server 5173
```
開啟 `http://localhost:5173/english-academy/p4/preview/`。此頁不是正式登入版，不連接任何使用者帳號。

## 正式整合前仍須補齊
1. **資料契約**：接上 P1 持久化資料、P2 真正 FSRS 排程和 P3 MCP 同步。正式 API/DB、OAuth、RLS 和 Edge 尚未經批准部署，不能用示範數據冒充實際成績。
2. **適性 AI 提案**：目前是確定性規則與 AI 建議的驗證器，未呼叫外部模型。真正的 AI 自適應教學／評分流程及人工覆核需另行驗證；不得接受 LLM 自行批准寫入、刪除或推定認證。
3. **CEFR 及語音**：A0 是自訂入門、A1–C2 是課程參考，不是官方語言能力證書。聽說技能要實際音訊／口語評測證據，不能僅憑文字。
4. **Android 真機與安全**：真實 A22 裝置、本人 Google OAuth、安全資源隔離、跨系統端對端及獨立安全複核，集中於經本人授權的正式驗收窗口。
5. **正式部署**：GitHub main、Supabase migration/Edge、Google allowlist、現有私有 Site 與費用變更都要本人另行批准，不得根據平行開發授權自動部署。
