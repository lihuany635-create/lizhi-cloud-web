## 1. 整體外形：普通家庭住宅
- **建築外框建議**：9.0 m（東西）× 8.0 m（南北），每層約 72 ㎡建築輪廓，兩層合計約 144 ㎡ **含牆與樓梯的概念建築面積**。尚非土地／建蔽率／結構實測；若不符合外部院地可調整。
- **樓層**：一樓、二樓外框大致相同；二樓不是縮小的小盒子。無強制陽台與地下室。
- **高度暫設**：一樓、二樓樓高約 3.0 m，待樓梯與結構尺寸核對。
- **風格**：一般雙層家庭住宅，淺灰／米色外牆、簡單坡屋頂或低坡屋頂、深色窗框、樸素大門；日常家具；拒絕豪宅雕塑、挑空大廳與巨型裝飾。
- **室外**：南側前院有步行入戶路；東南車位預留約 2.7×5.5m 作暫定車位包絡，配置一輛黑車；住宅街與鄰居外觀採背景低細節，不能把別家房子連入本宅。

## 4. 三項不可破壞的鏡頭連續條件
1. **完整行走路徑**：H2-01 床側→書桌→臥室正式門→二樓走廊→U型樓梯→一樓玄關→前院→唯一黑車，所有角色可通行，不用陽台門冒充臥室主門。
2. **主角窗景與實體車位**：H2-01 的南／東窗看得到**同一輛**黑車及住宅街；鏡頭俯仰、樹木和雨遮不得遮住設定中的視線；模型視錐應在灰模查驗。
3. **日夜連戲**：床、書桌、學生證位置、樓梯、門片和車位固定；時間與角色可攜道具使用場景狀態切換，不複製物件。

## 5. 供 S05 灰模驗證的最低條件
- 建築整體9×8m為可修改設計目標；兩層外周輪廓吻合、樓梯孔洞完全對位，門窗避免建築衝突。
- 樓梯淨寬概念≥0.9m、踏步和層高須按3.0m樓高計算；要另依實際所在地法規與用途檢核，不以此草案聲稱法定合格。
- 主要通道概念淨寬≥1.0m，門片與椅子展開時不能堵住。
- 一樓上下水集中西北及廚房側；二樓衛浴盡量落在一樓濕區上方。
- 針對1F/2F分別提交：帶尺寸的俯視圖、門窗及家具定位、樓梯剖面、角色視高動線、從H2-01窗看車位鏡頭。
- 原始 / 新灰模 / 候選 / 採用版本各自唯一，新增版不得覆寫舊GLB。
