# 工作台垃圾桶（2026-10-26）

需求：使用者要求補齊專案、圖片、工作紀錄的刪除操作。擴充既有工作台，保留動畫／模型專業rows、理財、正式工程圖與既有原檔。

## 操作
- 工作台右上「垃圾桶」：查看已刪項目、還原、永久刪除。
- 開啟專案→「刪除專案」；紀錄卡片→「刪除紀錄」；圖片卡片垃圾桶按鈕→「刪除圖片」。
- 一般刪除先確認、移入垃圾桶，從一般清單及AI接手摘要隱藏。還原原ID及內容，以新版本保存。
- 永久刪除只接受垃圾桶項目，需在網頁輸入「永久刪除」；不是空字串或一鍵清空。
- 刪除／還原均僅限本人已登入網頁；不新增AI刪除工具，bridge身份不能偽裝成author。
- 有動畫專業workId的專案只支援垃圾桶／還原，永久刪除受到保護。
- 含原圖或垃圾桶子項的專案，須先還原並清理子項；仍被圖片連結的紀錄，須先解除連結或處理圖片。避免孤兒原檔與斷鏈。

## 資料與安全
新增可選JSON欄位trash、trashAudit；無資料庫migration、不覆寫舊資料。原圖移入垃圾桶只移除一般索引，保留私有Storage原檔供還原；一般讀圖不能再取得其簽名URL。先前已發出的300秒連結會自然到期。

圖片永久刪除先以CAS保存purging狀態並禁止還原，再刪Storage，最後再次CAS清除垃圾桶項目。若網路／Storage／最後CAS失敗，仍保留清理中狀態，由本人重新整理後明確重試，不自動重送未知寫入。永久刪除非圖像項目會移除垃圾桶快照，保留最小異動證據。

永久刪除指「無法從工作台垃圾桶還原此項目」；既有匯出備份及異動歷史不被抹除。回復舊通用備份亦會尊重當前垃圾桶與永久刪除紀錄，不偷偷復活已刪紀錄。刪除支持紀錄會撤除任務無依據的PASS；還原紀錄不自動把任務核為PASS。
