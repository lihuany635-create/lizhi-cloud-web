## 3. 房間分區（位置優先、室內尺寸後校）

一樓：西北衛浴洗衣、西側中段U形樓梯、西南玄關／鞋區，中北廚房、東北餐廳、東南客廳，西側服務通道連接生活動線。平面 A-101 R00 為牆、門、窗的主要起點；I-101 R00 僅輔助家具配置。

二樓：西北共用衛浴、西側中段樓梯、南西父親房、東南主角房、東北多功能房與樓廊。主角房需保留窗邊看前院黑車的劇情鏡位，但**不得假設床邊也能看到車**。

## 4. 圖面採用優先序

1. **基礎分區／開口：**A-101、A-102 R00（目前工作台仍是設計稿，未核定）。
2. **屋頂與外表：**A-103、A-201~A-204 R01；R01是局部幾何修正，**並未**授權改動一、二樓門窗洞口。
3. **樓梯與門窗：**A-301、A-401、A-402 R01；與 A-101/A-102 發生衝突時先回報，禁止自補假門或梯間窗。
4. **人物動線與鏡位：**V-001 R00、V-002 R01；A-302 R00只能作歷史對照。
5. **家具體量：**I-101、I-102 R00及兩樓彩色家具參考；不得由效果圖反推精準牆長。
6. **材質／裝潢：**玄關、餐廳、客廳、廚房效果圖。只採風格、色彩、家具外型與燈光，不把其門窗位置或景深直接套入外殼。

## 6. 建模順序與驗證門檻

**P0 外殼與分區：**按A101/A102建立雙層灰模，先檢查牆、門、窗、二樓開孔、U型梯上下連通與樓層高度。

**P1 屋頂與立面：**以R01四向立面+屋頂平面修正，確認從南、北、西、東4向看都一致；先不增加西側窗。

**P2 可走動灰模：**建立基本家具碰撞盒、門扇開啟掃掠、梯間轉身與頭頂淨高，確認人物可從二樓主角房經梯到南側玄關。

**P3 場景敘事：**測試窗邊眼高、窗台、黑車停放點與攝影機遮擋，黑車只有一輛。

**P4 室內細修：**在幾何核對後依玄關／餐廳／客廳/廚房參考做溫暖淺木+米白系。每個家具和燈具須有獨立ID。

**P5 材質燈光和效能：**輸出自然日景及夜晚燈光比對，保留未加入後處理的可編輯場景，檢查穿模、比例與動畫鏡位。

## 7. 不可忽略的四項既有問題

- 樓梯：16級高算術吻合3m，但平台、孔洞、梁底、人頭淨高及梯廳衝突未在3D通過。
- 黑車視線：V-002 R01僅證明提案眼點靠窗時可能看見；床邊視角可能遭窗台遮擋，水平視錐與車位未驗。
- 結構：S-101 R00只是樓板與梯孔概念，不能做梁柱受力／施工安全結論。
- 基地：南側道路、前院、黑車位置的實際基地界與距離未核定。
