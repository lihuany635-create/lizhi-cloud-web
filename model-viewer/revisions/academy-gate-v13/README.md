## 原著支持 vs 新增美術設計

原著第五章描述：通學接駁車在學院附近放下趙義啟，凱薩在**校門附近等他**；第七章描述拉乎迪學院有百年以上歷史，冬季外牆舊而不破敗。原著未指定門柱、鐵門和校界寬度，因此本 V13 **校門外觀、校界位置及警衛亭均為可回復候選美術設計**，不是已正式核定的原著設定。
